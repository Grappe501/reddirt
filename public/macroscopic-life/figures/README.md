# Macroscopic Life — Final Figure Assets

This directory is the canonical public asset drop zone for the Macroscopic Life digital/print figure pipeline.

Expected filenames:

`fig-01.webp` through `fig-18.webp`

Frozen publication sequence:

`fig-02.webp` through `fig-16.webp`

Companion-only diagrams:

`fig-01.webp`, `fig-17.webp`, `fig-18.webp`

## Production rule

A final artwork file is a **visual base layer only**. It must not contain canonical scientific text that the publication depends on.

Titles, scientific labels, arrows with evidentiary meaning, axes, units, legends, evidence classes, test names, quantitative claims, captions, and scientific brakes remain deterministic site/publication text.

Until an asset is reviewed and its manifest status is changed from `fallback-svg`, the live site continues to render the existing deterministic React/SVG figure.

Do not create empty placeholder image files. A missing final asset is safer than a broken or misleading publication asset.
