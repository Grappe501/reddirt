# Sources

This folder will hold source notes, bibliographies, paper summaries, datasets, citation records, and chapter evidence packets for Macroscopic Life.

Every source note should identify:

- full citation;
- source type;
- date accessed;
- relevant claim IDs from `03-evidence-ledger.md`;
- key findings;
- limitations;
- whether the source supports, weakens, or reframes a claim;
- exact chapter(s) it may inform.

Primary literature and major reviews should be preferred whenever possible.
