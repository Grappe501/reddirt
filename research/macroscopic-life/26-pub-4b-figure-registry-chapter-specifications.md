# ACT I — THE WORLD WE CANNOT SEE

## CHAPTER 1 — THE MICROBE

### ML-B1-C01-H01 — The Intelligent Cell
- Class: **C — HYPOTHESIS / thought experiment**
- Format: HERO
- Priority: **P0**
- Placement: chapter opening
- Purpose: place the reader inside a cell whose direct observational world is tiny compared with the human organism it inhabits.
- Must show: local cellular environment; severe observational limitation; hints of larger organized processes outside the cell's accessible field.
- Must not show: a literal scientifically observed intelligent cell; a tiny human brain inside the cell; proof of a human/civilization analogy.
- Caption goal: explicitly identify the intelligent cell as an epistemic thought experiment.
- Source requirement: cellular environment references for physical plausibility; speculative status explicit.
- Accessibility: alt text must explain that intelligence is fictional and the point is observational limitation.

### ML-B1-C01-F01 — Observer Embedded in the System
- Class: **B — MODEL**
- Format: FIGURE
- Priority: **P0**
- Purpose: show the difference between an external observer seeing a whole and an embedded observer sampling local signals.
- Visual logic: whole human silhouette/system map on one side; tiny local observation window on the other.
- Caption goal: inability to see the whole does not establish either absence or presence.

### ML-B1-C01-F02 — Three Questions, Three Evidence Levels
- Class: **B — MODEL**
- Format: FIGURE
- Priority: P1
- Purpose: separate: hidden physical organization; changing biological individuality; possible higher-order individuality above familiar organisms.
- Caption goal: first two open the door; third remains unresolved.

### ML-B1-C01-S01 — From Cell to Question
- Class: **B/C**
- Format: SPREAD
- Priority: P1

- Production note: candidate to merge H01 + F01 in final layout.

# TOP PROTOTYPE QUEUE

These visuals should be prototyped before broad production because they define the system and test whether the doctrine works.

## PROTOTYPE 1 — ML-B1-C02-S01 — THE OBSERVER WINDOW

Why first: establishes the book's central visual language of limited windows and scale.

Must prove:
- A/B evidence separation works visually;
- zoom/camera motif works;
- eighth-grade comprehension works;
- figure can scale from print to web.

## PROTOTYPE 2 — ML-B1-C07-S01 — THE BODY ELECTRIC

Why: highest risk of accidental mysticism.

Must prove:
- physical electrical biology can look astonishing without glowing-aura imagery;
- molecule/ion → membrane → tissue hierarchy is understandable;
- source-backed scientific art can match the book's cinematic identity.

## PROTOTYPE 3 — ML-B1-C10-S01 — THE MEMORY CHAIN

Why: tests whether abstract functional definitions can become intuitive visual narratives.

Must prove:
- time can be represented cleanly;
- trace/persistence/retrieval are distinguishable;
- brain memory is not visually privileged as the only form.

## PROTOTYPE 4 — ML-B1-C14-S01 — THE CIVILIZATION TEST

Why: most important scientific restraint visual in the book.

Must prove:
- property presence and evidence for individuality remain distinct;
- strong civilization capabilities do not visually imply organismhood;
- uncertainty/weak evidence is legible without being visually dismissed.

## PROTOTYPE 5 — ML-B1-C16-S01 — ELEVEN WAYS TO BREAK MACROSCOPIC LIFE

Why: defines the theory as a testable research program.

Must prove:
- dense material remains approachable;

- the spread feels like scientific investigation rather than manifesto.

## PROTOTYPE 6 — ML-B1-C01-H01 / C16-H01 — INTELLIGENT CELL PAIR

- speculative status unmistakable;

# ACCESSIBILITY RECORD TEMPLATE

Every final figure must answer:

1. Can the main distinction be understood without color?
2. Are all labels readable at final print size?
3. Is reading order obvious?
4. Does alt text state the main information rather than merely describing appearance?
5. Is any scientific uncertainty encoded by more than hue alone?
6. If the image is speculative, does alt text say so?
7. Can a grayscale print still preserve the argument?

# CAPTION PRODUCTION TEMPLATE

For major figures:

**WHAT YOU ARE SEEING:** plain description.

**WHAT IS ESTABLISHED:** evidence-backed content.

**WHAT IS SIMPLIFIED:** necessary abstraction.

**WHY IT MATTERS:** relationship to chapter argument.

**DO NOT INFER:** only when a likely visual misreading is scientifically important.

Captions need not literally print these labels in the final book. They are the production checklist.

# FIGURE COMPLETION GATES

A figure is not `done` because the art looks finished.

## CLASS A GATE

- source-backed;
- mechanism accurate;
- scale honest;
- caption scientifically bounded;
- provenance complete;
- accessibility passed;
- rights/license clear;
- scientific review passed.

## CLASS B GATE

- accurately represents the book's analytical framework;
- does not masquerade as measured data;
- categories/causal relationships clear;
- accessibility passed;
- caption identifies model status when needed.

## CLASS C GATE

- hypothesis status unmistakable;
- no invented mechanism presented as real;
- no scientific-imaging mimicry likely to deceive;
- caption/alt text explicit;
- emotional impact does not overwhelm evidence boundary.
