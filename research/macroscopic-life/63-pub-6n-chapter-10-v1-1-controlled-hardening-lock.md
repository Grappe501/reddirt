# HARDENING 1 — FUNCTIONAL MEMORY DEFINITION

Preserve the existing comparative definition:

> **Memory is information from the past retained in a physical form and later made causally available in a way that changes a future behavior or state.**

Immediately add:

> **This is an intentionally functional definition, but it does not make every history-dependent physical process a useful memory system. The retained state must be identifiable, causally relevant to a later response, and informative enough that including the system's history improves explanation or prediction beyond an adequate description of its present state alone.**

New mandatory firewall:

> **HISTORY DEPENDENCE ≠ FUNCTIONAL MEMORY BY DEFAULT.**

Scientific consequence:

- hysteresis alone does not automatically qualify;
- path dependence alone does not automatically qualify;
- material fatigue alone does not automatically qualify;
- a legacy effect alone does not automatically qualify;
- historical variables must earn explanatory or predictive relevance.

# HARDENING 2 — INFORMATION WITHOUT SEMANTIC SMUGGLING

Preserve:

> **INFORMATION MUST HAVE A PHYSICAL CARRIER AND A CAUSAL PATHWAY IF IT IS TO DO WORK IN THIS ARGUMENT.**

Immediately clarify:

> **Here, information does not mean meaning floating in matter. It means a physically instantiated difference whose state carries statistical or functional consequences relevant to distinguishing histories or constraining later responses.**

Then:

> **Calling a state informative does not establish that the system interprets it, represents it consciously, or assigns it meaning.**

This establishes the hierarchy:

`PHYSICAL DIFFERENCE`
→ possibly `STATISTICAL INFORMATION`
→ possibly `FUNCTIONAL RELEVANCE`
→ not automatically `INTERPRETED MEANING`
→ not automatically `REPRESENTATION`
→ not automatically `CONSCIOUSNESS`

New compact firewall:

> **INFORMATION ≠ INTERPRETATION ≠ CONSCIOUS MEANING**

# MODEL-COMPETITION LOCK

Preserve all four models.

## Model A — Component Memory

Individual agents remember and act.

## Model B — Artifact Storage

Records preserve information later used by agents.

## Model C — Organizational Memory

Rules, roles, routines, archives, distributed processes, and access structures preserve functionally relevant information across personnel turnover.

## Model D — Higher-Order Individual Memory

A stronger model requiring genuinely higher-level variables that improve prediction beyond A–C.

Mandatory rule:

> **DO NOT INVOKE A HIGHER-ORDER INDIVIDUAL MEMORY MODEL UNTIL IT PREDICTS SOMETHING THE LOWER-LEVEL MODELS DO NOT.**

And:

> **ORGANIZATIONAL MEMORY IS EVIDENCE OF ORGANIZATIONAL MEMORY. A HIGHER-ORDER INDIVIDUAL MUST EARN ITS OWN EVIDENCE.**

# ENDNOTE / RESEARCH ANCHORS

Preserve the v1.0 working set, with claims scoped as follows.

## [1] Neural memory / engrams

Josselyn, Köhler & Frankland (2015); Guskjolen & Cembrowski (2023); Zaki & Cai (2025).

Supports causal contribution of neuronal ensembles/plasticity in particular paradigms, not one-memory/one-location storage.

## [2] Adaptive immune memory

Lam, Lee & Farber (2024); Akkaya, Kwak & Pierce (2020); Fooksman, Jing & Park (2024).

Supports multiple cellular/effectory contributors and context-dependent durability.

## [3] Trained immunity

Netea et al. (2020); Hajishengallis, Netea & Chavakis (2023).

Use only with explicit distinction from adaptive immune memory.

## [4] Cellular / epigenetic memory

Stewart-Morgan, Petryk & Groth (2020); Palozola, Lerner & Zaret (2019).

Supports context-specific persistence/re-establishment of cell state through mitosis; does not license broad transgenerational claims.

## [5] Positional memory

Otsuki et al. (2025), `Molecular basis of positional memory in limb regeneration`, *Nature* 642:730–738.

Use for experimentally studied salamander/axolotl connective-tissue positional states; do not generalize to a universal position code.

## [6] Organizational memory

Walsh & Ungson (1991); Levitt & March (1988); Stein (1995).

Supports organizational-memory terminology around retention/retrieval/routines/artifacts while preserving the anthropomorphism warning.
