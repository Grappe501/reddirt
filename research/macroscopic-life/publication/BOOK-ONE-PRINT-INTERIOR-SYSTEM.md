# Macroscopic Life — Book One Print Interior System

## Status

**DESIGN SYSTEM LOCK — FINAL PDF GENERATION REQUIRES RC1 FREEZE**

The print edition should feel like a serious scientific field book that occasionally opens into visual wonder: restrained, legible, documentary, and exact.

## Provisional physical format

- Trim: **6 × 9 in**, provisional until printer/distributor specification is chosen.
- Body: single-column long-form reading.
- Interior: cream/white paper field; deep navy/blue-black reserved for act openings, rules, labels, and controlled visual moments.
- Figures: color-capable master, but every figure must survive a grayscale legibility proof.
- Bleed: only for deliberately full-bleed act/figure treatments; otherwise figures remain inside safe area.

No printer-specific bleed, gutter, spine, paper, or binding values are invented here.

## Page architecture

### Front matter

Half-title → title page → copyright/edition placeholder → scientific-method note → contents.

Commercial metadata remains visibly OPEN until approved.

### Act openings

Each act begins recto where practical. Use a high-contrast editorial opening with act number/title and a short orientation line drawn only from frozen canon. Do not write new scientific prose for decoration.

### Chapter openings

Chapter number and canonical title receive generous vertical space. Body begins on the same page unless pagination creates an obviously weak opening. No ornamental epigraphs unless already canonical and sourced.

### Body text

Prioritize sustained reading: moderate measure, generous leading, restrained paragraph spacing, no excessive boxes. The page should disappear behind the argument.

### Figures

Figures 2–16 use only verified R3 publication assets. Placement hierarchy:

1. near first substantive reference;
2. same spread when practical;
3. never shrink below deterministic-copy legibility;
4. caption remains physically associated with figure;
5. never crop away scientific labels, brakes, legends, axes, caveats, or test names.

A missing asset is a production blocker, not permission to redesign.

### Captions

Figure number + concise canonical caption. Caption typography must be visually distinct from body but fully readable. Scientific brake language remains part of the figure/caption system when locked.

### Endnotes

Reader text uses note markers without interrupting paragraph rhythm. Endnotes remain grouped in back matter for the print edition. Note numbering is exactly 1–45.

### Bibliography

Bibliography follows endnotes. Hanging-indent treatment. Preserve verified metadata exactly; no normalization that introduces unverified fields.

## Running furniture

- Front matter: no running heads.
- Chapter body: verso may carry book title; recto may carry current chapter title.
- Page numbers: restrained outside-bottom or centered-bottom system chosen at layout implementation.
- Act-opening and chapter-opening pages may suppress running heads.

## Typography contract

Use legally distributable production fonts chosen at implementation. Do not commit or distribute font binaries through this project merely to satisfy layout. Required roles:

- editorial serif for body and figure-title continuity;
- restrained sans for technical labels, notes, folios, and navigation;
- tabular/monospaced treatment only where genuinely useful.

The exact font family is a production choice, not scientific canon.

## Hostile print proof

Every PDF proof must be checked for:

- orphaned headings;
- widows/orphans that damage reading rhythm;
- broken note markers;
- figure/caption separation;
- unreadable figure copy;
- accidental rasterization of body text;
- clipped glyphs;
- broken special symbols such as `≠`;
- missing Eleven Test names;
- bad page turns around act/chapter openings;
- excessive blank pages;
- bibliography line-wrap failures;
- grayscale figure failure;
- accidental editorial/build-note leakage.

## Immutable publication doctrine

Layout may change presentation. It may not change the frozen scientific argument.
