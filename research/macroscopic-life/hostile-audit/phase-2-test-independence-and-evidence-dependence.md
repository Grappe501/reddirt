# 1. Dependence families

The Eleven Tests do not form eleven statistically independent measurements. They form several partially overlapping **evidence families**.

## Family A — Boundary / causal integration

- Test 1 Boundary Perturbation
- Test 2 Integration Ablation
- Test 9 Higher-Level Intervention

These can all respond to the same underlying causal architecture.

If cutting a communication layer changes system performance, that one experiment could appear to support all three.

Therefore the book must not count one perturbation as three independent victories.

### Independence rule

A strong program should distinguish:

- **where the boundary is**;
- **whether internal relations are required for whole-level capability**;
- **whether a macro-variable can be intervened upon in a way that adds causal/predictive leverage beyond lower-level descriptions**.

One experiment may inform all three, but the evidentiary ledger must record that dependence.

---

## Family B — persistence / memory / repair

- Test 5 Memory Turnover
- Test 7 Repair Autonomy

Both concern persistence through disruption.

A system that restores infrastructure after damage may also preserve information through component turnover. Those are related but not identical.

### Independence rule

Memory Turnover asks whether **causally useful state from the past survives component replacement**.

Repair Autonomy asks whether **damage triggers restoration of organization or function without requiring an external designer to reconstruct the whole state by state**.

Persistent records alone do not prove autonomous repair. Repair alone does not prove memory across turnover.

---

## Family C — information / prediction / macrocausation

- Test 6 Prediction Advantage
- Test 8 Whole-Only Information
- Test 9 Higher-Level Intervention

This is the most serious dependence cluster.

A useful macroscopic variable can simultaneously improve prediction, summarize synergistic information, and support interventions. If the same model comparison is used for all three, we could accidentally count one discovery three times.

### Independence rule

Prediction Advantage asks:

> Does the macro-description improve held-out prediction relative to serious lower-level baselines?

Whole-Only Information asks:

> Is there information in relationships among components that is not recoverable from components treated independently under the chosen decomposition?

Higher-Level Intervention asks:

> Can intervention on a properly defined macro-variable produce reproducible downstream consequences that improve causal explanation relative to alternative decompositions?

Prediction, information decomposition, and intervention are related mathematical questions. They are not interchangeable.

---

## Family D — evolutionary individuality

- Test 3 Conflict Suppression
- Test 10 Reproduction/Heredity

These are strongly related through major-transitions theory.

Systems moving toward evolutionary individuality often require mechanisms that reduce destructive lower-level conflict and some pathway by which higher-level organization persists across generations.

But they are not identical.

A system may suppress conflict without reproducing as a higher-level lineage. A system may reproduce structures culturally or institutionally without satisfying a biological heredity criterion.

### Independence rule

Do not redefine reproduction merely because civilization possesses cultural transmission.

Reproduction/Heredity remains one of the strongest current failure points for Model D.

---

## Family E — energetic organization

- Test 4 Energetic Organization

This is comparatively independent, but it is also comparatively weak as a discriminator.

Many nonliving complex systems dissipate energy and maintain nonequilibrium organization.

Therefore Energetic Organization can be necessary or informative without being highly diagnostic of individuality by itself.

### Independence rule

Energy throughput is evidence of organized dynamics, not a shortcut definition of life.

---

## Family F — model discrimination

- Test 11 Model Competition

This sits above the other ten.

It asks whether the complete higher-order hypothesis explains or predicts observations better than serious alternatives after complexity penalties, dependence, and lower-level explanations are accounted for.

### Independence rule

No number of weakly independent positives can substitute for Test 11.

# 3. New rule: evidence units, not test counts

The current framework should not speak as if `7 of 11 tests passed` automatically means stronger evidence than `5 of 11`.

That would be scientifically weak because the tests are not equally diagnostic and are not mutually independent.

Macroscopic Life should therefore distinguish:

- **test outcome** — what happened on a named Test;
- **evidence unit** — the underlying experiment/dataset/perturbation;
- **dependence family** — which Tests may be drawing from the same causal signal;
- **diagnostic weight** — how strongly the result discriminates Model D from Models A–C;
- **replication status** — whether the effect survives independent datasets, populations, time windows, or interventions.

A single evidence unit may inform multiple Tests, but it counts as one underlying evidentiary event in any aggregate score unless independently replicated through different methods.

# 5. Weighted interpretation

Do **not** create arbitrary fixed weights yet.

A fixed point system would create false precision before empirical calibration.

Instead, use four qualitative classes initially:

### Class 1 — weakly diagnostic

Examples: energetic throughput, generic complexity, generic adaptation.

These can support organization but rarely distinguish individuality.

### Class 2 — moderately diagnostic

Examples: durable memory through turnover, autonomous repair, conflict suppression.

### Class 3 — strongly diagnostic

Examples: whole-only information that survives serious decomposition controls, macro-level intervention with incremental causal leverage, reproduction/heredity at the proposed level.

### Class 4 — decisive only through comparison

Model Competition.

A Class 3 result can still fail if Model C predicts it equally well.

# 6. Candidate Test 12 — Generative Recurrence hostile review

The proposed `Generative Recurrence / Independent Convergence` test is interesting, but Phase 2 finds that it is **not yet independent enough to promote into the canonical Eleven**.

It overlaps strongly with:

- Test 5 Memory Turnover;
- Test 6 Prediction Advantage;
- Test 8 Whole-Only Information;
- Test 10 Reproduction/Heredity;
- Test 11 Model Competition.

Its strongest value is currently as a **research module** asking whether a macro-state predicts independent convergence after controlling for diffusion, shared cognition, material constraints, environment, common ancestry, and accumulated prerequisite knowledge.

### Phase 2 verdict on Test 12

**DO NOT PROMOTE YET.**

Keep the canonical Eleven unchanged.

Develop Generative Recurrence as a Macroscope module. Promote only if it produces discriminatory evidence that cannot be adequately represented by Tests 5, 6, 8, 10, and 11.

This protects the framework from test inflation.
