# MACROSCOPIC LIFE — PUB-4G ACCESSIBILITY & CROSS-MEDIA PASS

## Status

**PUB-4G COMPLETE — ACCESSIBILITY / CROSS-MEDIA DOCTRINE LOCKED**

PUB-4G ensures that Book One communicates the same scientific meaning across print, ebook, web, presentation, screen-reader, grayscale, low-vision, and audiobook-companion contexts.

The governing principle is:

> **No format may become more certain, more mystical, less testable, or less understandable than the controlling manuscript and visual doctrine.**

Accessibility is not a late compliance layer. It is part of the epistemic design of the book.

---

# 1. CORE ACCESSIBILITY STANDARD

Every substantive visual must survive five forms of loss:

1. **COLOR LOSS** — reader cannot distinguish hue reliably.
2. **SIZE LOSS** — figure is reduced for ebook/mobile/slide use.
3. **VISION LOSS** — figure is consumed through alt text or screen reader.
4. **CONTEXT LOSS** — figure is detached from surrounding prose or screenshot.
5. **MEDIA LOSS** — figure is unavailable entirely, as in audio-only use.

If the scientific argument collapses under one of these conditions, the visual system is incomplete.

---

# 2. COLOR-INDEPENDENCE LOCK

No scientific or conceptual distinction may depend on color alone.

Every distinction must also use at least one of:

- shape;
- pattern;
- line style;
- border treatment;
- text label;
- position;
- iconographic form;
- value/lightness contrast.

Examples:

- OBSERVED / MODEL / HYPOTHESIS cannot be distinguished only by blue/yellow/purple.
- STRONG / MODERATE / WEAK cannot rely only on green/yellow/red.
- competing models cannot be encoded only as two colors.
- inside/outside boundaries must remain legible in grayscale.

---

# 3. GRAYSCALE STANDARD

Every P0 figure receives a grayscale review.

Pass criteria:

- primary hierarchy remains visible;
- text contrast remains strong;
- line types remain distinguishable;
- uncertainty remains legible;
- speculation markers remain obvious;
- warning/brake elements do not disappear;
- strong and weak evidence states remain distinguishable.

The print edition may use color, but the argument must not depend on it.

---

# 4. TYPOGRAPHIC ACCESSIBILITY

Figures must use typography appropriate to final reproduction size.

Rules:

- avoid ultra-light weights;
- avoid condensed technical labels when plain language fits;
- major labels should be readable without magnification at final print size;
- supporting labels should not become microscopic in full-spread reductions;
- do not place text over visually noisy backgrounds without sufficient contrast;
- avoid all-caps paragraphs;
- avoid long italic passages inside figures;
- use direct labeling instead of tiny legends wherever possible.

The figure should remain understandable when reproduced at roughly 70–80% of intended size.

---

# 5. READING ORDER

Every complex figure needs an obvious reading path.

Preferred methods:

- left → right;
- top → bottom;
- numbered sequence;
- clearly defined center-outward structure;
- repeated panel grammar.

Avoid layouts where the eye must guess which arrow, caption, or box comes next.

For digital accessibility, the same logical order must be reflected in alt text and document structure.

---

# 6. ALT-TEXT DOCTRINE

Alt text communicates the **information of the figure**, not merely its appearance.

Bad:

`Diagram with circles and arrows.`

Good:

`Conceptual diagram showing three separate levels—macroscopic pattern, macroscopic organization, and higher-order individuality—with test gates between them. The diagram emphasizes that a system can display a large-scale pattern without qualifying as an individual.`

Alt text should answer:

1. what kind of visual this is;
2. what the major elements are;
3. what relationship or comparison matters;
4. what conclusion the reader should take;
5. what conclusion is explicitly not established, when scientifically important.

---

# 7. ALT-TEXT EVIDENCE CLASS LOCK

Every substantive alt text begins conceptually from the figure's evidence class.

Examples:

### CLASS A
`Scientific schematic showing...`

### CLASS B
`Conceptual model showing...`

### CLASS C
`Speculative illustration exploring...`

A speculative visual must never become more factual in alt text than it is visually.

---

# 8. LONG DESCRIPTION STANDARD

Some dense visuals cannot be responsibly compressed into one sentence.

P0 candidates for long descriptions include:

- Observer Window;
- Body Electric;
- Memory Chain;
- Civilization Test;
- Eleven Ways to Break Macroscopic Life;
- major transitions;
- final scale spread.

Long descriptions should be stored as separate production assets and linked in accessible digital editions where supported.

They should reproduce the figure's reasoning in prose rather than catalog every decorative detail.

---

# 9. HOW-TO-READ-THIS DEVICE

Dense figures may include a short plain-language instruction before interpretation.

Examples:

> **How to read this:** the left column asks whether civilization has a property. The right column asks a different question: whether that property is evidence that civilization is one individual.

or

> **How to read this:** follow the timeline from past event to physical trace, then ask whether that trace remains available long enough to change a later response.

This device is encouraged when it reduces cognitive load without talking down to the reader.

---

# 10. SCREEN-READER LOGIC

Accessible digital structure should preserve:

- chapter hierarchy;
- figure number;
- figure title;
- evidence class;
- alt text;
- caption;
- source note/endnote reference;
- long-description link when present.

Decorative visuals should be marked decorative rather than described unnecessarily.

Text embedded inside images should also exist in machine-readable text where practical.

---

# 11. EBOOK RESPONSIVENESS

Figures cannot assume a fixed two-page print spread.

Each major spread requires an ebook adaptation plan.

Possible approaches:

- stacked panels;
- vertically scrolling sequence;
- one overview image plus enlarged subfigures;
- tappable/zoomable figure;
- text-first mobile rendering with figure after explanatory setup.

The ebook version must preserve conceptual order even when page-turn choreography is impossible.

---

# 12. MOBILE WEB STANDARD

For web companion use:

- no essential hover-only information;
- touch targets large enough for mobile interaction;
- annotations expandable without covering the entire figure;
- figures responsive to narrow screens;
- no tiny horizontal multi-column matrices without mobile alternative;
- interactive animation must have static equivalent;
- animation must not be required to understand the argument.

The reader should be able to understand the figure on a phone without rotating into landscape unless the content truly requires it.

---

# 13. MOTION / ANIMATION STANDARD

Interactive or presentation versions may animate:

- zoom through scales;
- signal propagation;
- temporal sequences;
- regeneration steps;
- memory-chain progression;
- network integration;
- test perturbations.

Motion rules:

- animation illustrates sequence; it does not add unsupported causation;
- no pulsing/glowing effects as generic shorthand for intelligence/life;
- avoid rapid flashing;
- provide pause/replay controls when applicable;
- provide static equivalent;
- respect reduced-motion preferences on web.

---

# 14. AUDIOBOOK COMPANION STANDARD

Book One must remain fully understandable without a visual companion.

The audiobook may occasionally say something like:

`A companion figure for this chapter shows the same distinction visually.`

But the audio narrative must still explain the idea in complete spoken language.

Do not say:

`As you can see in Figure 12...`

when the figure is necessary to understand the next argument.

Audio companion figures are supplementary.

---

# 15. SPOKEN FIGURE TRANSLATION

Every P0 figure receives a spoken-equivalent paragraph.

Example — Pattern / Organization / Individuality:

> A large-scale pattern is the first level. If the pattern is maintained through meaningful interactions and constraints at that scale, we can discuss macroscopic organization. But neither pattern nor organization automatically makes a new individual. That requires additional evidence: boundaries, integration, continuity, self-affecting regulation, and better explanation or prediction than the component model alone.

The spoken version should preserve both the conclusion and the brake.

---

# 16. PRESENTATION / LECTURE STANDARD

Slides may reveal complex figures progressively.

Rules:

- reveal mechanism in the same order as the book;
- never remove the MODEL/HYPOTHESIS marker during animation;
- never crop off scientific caveats to create a cleaner slide;
- never convert qualitative states into scores for dramatic charts;
- all presentation figures inherit the same evidence class and caption doctrine;
- a speaker should be able to state the prohibited inference aloud.

Presentation adaptation may simplify density, not scientific meaning.

---

# 17. SOCIAL / SCREENSHOT STANDARD

Because figures will circulate outside the book, standalone versions of high-risk visuals need embedded epistemic context.

Required for Class C and selected high-risk Class B figures:

- figure ID or title;
- MODEL / HYPOTHESIS / THOUGHT EXPERIMENT marker;
- one-sentence brake;
- Macroscopic Life attribution where appropriate.

Never prepare a social crop that removes the uncertainty marker because it looks cleaner.

---

# 18. LOW-VISION STANDARD

Low-vision review asks:

- can the primary relationship be understood at 200% zoom without content overlap?
- do labels remain crisp?
- is contrast adequate?
- are thin-line dependencies avoided?
- does important content disappear when adjacent colors become hard to distinguish?
- is whitespace used to separate conceptual regions?

Do not use dense decorative texture behind information-bearing elements.

---

# 19. COGNITIVE ACCESSIBILITY

Macroscopic Life contains difficult concepts. Visual accessibility therefore includes cognitive load.

Rules:

- no figure should introduce more new terms than the surrounding prose can support;
- define unfamiliar terms before or within the figure;
- prefer one major conceptual job per figure;
- split diagrams rather than stack five unrelated mechanisms;
- use repeated visual grammar across chapters;
- keep labels plain-language first, technical term second;
- show the allowed conclusion and the brake close together.

The goal is not simplification by deletion.

It is comprehension by structure.

---

# 20. EIGHTH-GRADE FIGURE TEST

For every P0 figure, an intelligent fourteen-year-old should be able to answer:

1. What am I looking at?
2. What changes or differs?
3. What is the main point?
4. Is this observed science, a model, or speculation?
5. What does this image **not** prove?

If the reader cannot answer at least four of five after a short caption, revise the figure.

---

# 21. SCIENTIST FIGURE TEST

A scientifically literate reviewer should be able to answer:

1. what empirical claim is being made;
2. what is schematic;
3. which causal arrows are established versus conceptual;
4. what uncertainties are being compressed;
5. whether evidence class is honest;
6. what source family supports the figure.

The eighth-grade test and scientist test must both pass.

# 23. HIGH-RISK FIGURE ACCESSIBILITY SPECS

## THE OBSERVER WINDOW

Must work as nested/partitioned space even in grayscale.

Alt-text emphasis:
changes in detectable range, not changes in physical reality.

Spoken equivalent:
sensory, spatial, temporal limits.

## THE BODY ELECTRIC

Do not encode ions only by color.

Use ion labels/symbols plus shapes/patterns.

Alt text must state that bulk fluids remain nearly electrically neutral.

## THE MEMORY CHAIN

Timeline order must remain obvious without arrows alone.

Use numbered stages or explicit sequence labels.

## THE CIVILIZATION TEST

Mobile version should become stacked criterion cards rather than microscopic table columns.

Every card repeats both questions:

`PROPERTY PRESENT?`

and

`EVIDENCE FOR INDIVIDUALITY?`

## ELEVEN WAYS TO BREAK MACROSCOPIC LIFE

Mobile/audio version processes tests one at a time.

Strengthening and weakening outcomes retain equal emphasis.

## FINAL WE ARE THE MICROBE SPREAD

Alt text must explicitly state that the outer scale is unresolved and hypothetical.

Audio version must not imply that the visual reveals a larger organism.

Some PUB-4F reveals depend on a physical page turn.

Digital equivalents should preserve **sequence**, not necessarily geometry.

3. `Now throw it away.`;

# 25. TEXT-ONLY ZONES ARE ACCESSIBLE BY DESIGN

PUB-4F established important text-only moments.

These remain text rather than being converted into decorative quotation art unless accessibility and reading order are preserved.

High-value text-only lines include:

- `The whole is the parts organized.`
- `Error is evidence that prediction actually occurred.`
- `Analogy is not evidence.`
- `A theory that cannot lose is not a theory worth keeping.`
- final `we are the microbe.`

Text itself is often the most accessible medium.

---

# 26. SYMBOL / FORMULA ACCESSIBILITY

Visual chains such as:

**SIGNAL ≠ INFORMATION ≠ INTEGRATION ≠ INTELLIGENCE ≠ AGENCY ≠ CONSCIOUSNESS**

must always have plain-language equivalents in text/alt/audio.

Likewise arrows must not carry meaning that exists nowhere else.

Screen-reader versions should avoid reading a long sequence of symbols without explanatory phrasing.

---

# 27. ACCESSIBLE CAPTION DOCTRINE

Captions must not begin with dense source detail.

Recommended order:

1. plain-language meaning;
2. mechanism/model explanation;
3. simplification/caveat;
4. source/endnote marker.

For Class C:

1. identify speculative status;
2. identify real ingredients;
3. explain imagined arrangement;
4. state prohibited inference.

---

# 28. RIGHTS / ACCESSIBILITY INTERACTION

If a licensed external figure cannot be modified enough to meet accessibility and scientific-brake requirements, do not use it merely because rights are available.

Prefer original/redrawn figures when necessary to achieve:

- direct labels;
- contrast;
- grayscale resilience;
- alt-text clarity;
- simplified educational hierarchy;
- evidence-class consistency.

# 29. ACCESSIBILITY QA PASS

Before PUB-4H visual lock, each P0 visual is reviewed in this order:

1. full-color print;
2. grayscale;
3. reduced-size print;
4. ebook/mobile;
5. screen-reader alt text;
6. spoken equivalent;
7. detached screenshot;
8. scientific interpretation;
9. eighth-grade comprehension.

Failure in any essential mode returns the figure to production.

---

# 30. CROSS-MEDIA SCIENTIFIC EQUIVALENCE

The same figure may look different across media.

The scientific claim may not.

Example:

Print Civilization Test = matrix.

Mobile Civilization Test = stacked cards.

Audio Civilization Test = criterion-by-criterion spoken comparison.

Presentation Civilization Test = progressive reveal.

All four must preserve:

- property presence separate from individuality evidence;
- qualitative uncertainty;
- reproduction/heredity/selection weaknesses;
- no organism conclusion.

Layout changes.

Meaning does not.
