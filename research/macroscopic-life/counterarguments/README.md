# Counterarguments

This folder is reserved for adversarial work against the Macroscopic Life framework.

The project should actively preserve:

- conventional explanations for apparent cross-scale similarities;
- anthropomorphism and apophenia risks;
- objections from biology, physics, philosophy of mind, cosmology, and complexity science;
- failed analogies;
- rejected hypotheses;
- evidence that weakens favored interpretations;
- falsification criteria;
- alternative models that explain the same observations with fewer assumptions.

A theory map without a serious opposition map is incomplete.
