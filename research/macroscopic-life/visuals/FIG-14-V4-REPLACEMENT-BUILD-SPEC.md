## Why Figure 14 must be replaced

The frozen V3 register contains the obsolete line:

> Current evidence supports Model C, not Model D.

Book One no longer uses a Model D taxonomy. Final doctrine is A/B/C/U/X, and Model C is always property-specific. The old Figure 14 therefore cannot enter publication.

The useful scientific core of the old figure is retained:

> **COMPLEXITY ≠ INTEGRATION ≠ INDIVIDUALITY**

The replacement must visualize the burden of moving from a complicated collection to an individuality claim without implying a universal linear ladder.

## Figure 14 V4 title

# MANY CAN ACT TOGETHER WITHOUT BECOMING ONE

## Primary visual structure

Use a horizontal three-state comparison, not an upward staircase.

### PANEL A — COMPLEX COLLECTION

Visual: many distinguishable components sharing a region, with numerous local interactions but no privileged whole boundary.

Label:

**COMPLEXITY**

Supporting copy:

> Many parts. Many interactions. Rich dynamics.

Scientific brake:

> Complexity alone does not establish a higher-level individual.

### PANEL B — INTEGRATED SYSTEM

Visual: same class of components with stronger coupling, coordinated flows, feedback, and a candidate boundary. Keep component identities visibly present.

Label:

**INTEGRATION**

Supporting copy:

> Parts can become mutually dependent, coordinated, and constrained by larger-scale organization.

Scientific brake:

> Integration can be real before stronger individuality is established.

### PANEL C — INDIVIDUALITY CLAIM UNDER TEST

Visual: candidate higher-level unit outlined, but with a measurement/test frame around it rather than a crown, check mark, or organism icon. Show small callouts representing framework-dependent criteria: membership consequences, persistence through turnover, conflict mediation, reproduction/lineage, and causal/predictive organization.

Label:

**INDIVIDUALITY — FRAMEWORK SPECIFIED**

Supporting copy:

> The claim becomes scientific only after the relevant individuality framework is named and its criteria survive serious rivals.

## Dominant bottom brake

> **COMPLEXITY ≠ INTEGRATION ≠ INDIVIDUALITY**

## Secondary doctrine line

> **EVIDENCE FOR ONE KIND OF INDIVIDUALITY CANNOT SILENTLY SUBSTITUTE FOR EVIDENCE FOR ANOTHER.**

## Model callout

Do not show Model D.

If a model callout is visually useful, use only:

> **MODEL B CAN BE REAL ORGANIZATION. MODEL C MUST BE EARNED FOR THE SPECIFIC PROPERTY BEING TESTED.**

This callout is optional. The figure works without model labels and may be scientifically cleaner without them.

## Explicit prohibitions

Figure 14 V4 must not:

- depict complexity → integration → individuality as inevitable progress;
- use an ascending staircase, evolutionary arrow, crown, apex, or hierarchy implying advancement;
- imply every integrated system is an organism;
- imply one individuality framework settles all others;
- imply a useful boundary proves individuality;
- imply Model B is failure;
- use Model D;
- use consciousness, mind, brain, or person icons as the destination;
- depict Earth as the final stage;
- use mystical glow/aura imagery.

## Caption

**Figure 14. Complexity, integration, and individuality are different claims.** A system can contain many interacting parts without functioning as a higher-level individual, and it can become strongly integrated without satisfying every scientific framework for individuality. The relevant framework must be stated before the evidence is interpreted. Evidence for physiological, developmental, ecological, organizational, or evolutionary individuality cannot silently substitute across categories.
