# P1-1 — THE GRID STILL LOOKS LIKE ONE UNIVERSAL MEMORY MECHANISM

This is the most important problem.

All four rows are placed under the same five columns with identical arrow structure. A reader can easily infer:

> neural memory, immune memory, cellular memory, and institutional memory are four versions of the same biological process.

That is not what the architecture says.

The intended claim is weaker:

> These systems can be compared using the same analytical questions: what happened, what physical state changed, what persisted, how did that state later become causally relevant, and what response differed?

Their mechanisms are radically different.

### Required revision

The figure must visibly label the five columns as something like:

**COMPARATIVE QUESTIONS — NOT A UNIVERSAL MECHANISM**

or

**ANALYTICAL SCAFFOLD — DIFFERENT SYSTEMS, DIFFERENT MECHANISMS**

A strong horizontal firewall should state:

> **SIMILAR FUNCTION ≠ IDENTICAL MECHANISM**

and

> **THE WORD `MEMORY` DOES NOT CREATE A COMMON SUBSTRATE.**

This cannot be buried in a caption. It must be visually structural.

# P1-2 — `REACTIVATION / ACCESS` IS TOO STRONG AS A UNIVERSAL STAGE

For external records, `access` is natural.

For neural memory, reactivation can be appropriate in some contexts.

For adaptive immune memory, re-exposure can activate memory populations.

But for persistent developmental or cellular state, the state may continuously constrain response rather than sit dormant until literally `reactivated.`

The architecture deliberately allowed:

> reactivated, read, interpreted, **or otherwise made causally available**.

### Required revision

Change the universal stage heading to:

**4. LATER CAUSAL AVAILABILITY**

Subline:

> **The retained state becomes relevant to a later process.**

Individual rows may then use system-specific terms such as:

- neural: cue-dependent reactivation / altered circuit dynamics;
- immune: re-exposure activates memory populations;
- cellular/developmental: retained state alters response to later conditions;
- external/institutional: a later agent/system accesses the record.

This is more accurate and prevents storage-computer metaphors from colonizing biology.

# P1-3 — THE CELLULAR/DEVELOPMENTAL ROW OVERGENERALIZES EPIGENETIC INHERITANCE

The figure currently says:

> `Altered state persists through cell divisions.`

and earlier gives `chromatin state` as the example.

This can be scientifically valid in particular systems, but the current presentation looks universal.

It also risks activating the popular misconception that epigenetic marks are straightforwardly copied forever or that developmental memory is simply `epigenetic marks inherited by daughter cells.`

### Required revision

Use a more controlled exemplar.

Preferred deterministic copy:

**Past developmental condition**
→ **persistent regulatory / positional state**
→ **state persists for a biologically relevant interval, sometimes through cell division**
→ **later conditions interact with retained state**
→ **later cell or tissue response differs**

Mandatory brake:

> **CELLULAR MEMORY ≠ EVERY EPIGENETIC CHANGE**

and, if mitosis is shown:

> **PERSISTENCE ACROSS CELL DIVISION ≠ TRANSGENERATIONAL INHERITANCE ACROSS ORGANISMS**

The visual should avoid making methyl tags or chromatin marks the universal icon for cellular memory.

# P1-4 — THE NEURAL ROW MAKES MEMORY LOOK LIKE ONE SYNAPSE OR ONE REACTIVATED CIRCUIT

The figure says:

> `Synaptic strength or structure is modified`

then

> `Same circuit can be reactivated by a later cue.`

These statements can describe relevant mechanisms, but together they visually suggest a simple one-memory/one-circuit storage model.

Human and animal memory is more distributed and mechanistically diverse than this panel implies.

### Required revision

Use broader copy:

**Experience alters neural activity and plasticity**
→ **changes can persist across synapses, cells, and circuits**
→ **later cues interact with the altered network state**
→ **later behavior or neural response differs**

Brake:

> **NEURAL MEMORY ≠ ONE MEMORY STORED IN ONE SYNAPSE**

No need to teach systems consolidation in the figure, but avoid false simplicity.

# P1-5 — THE IMMUNE ROW'S OUTPUT IS TOO NARROW AND `TARGETED` IS SEMANTICALLY LOADED

The figure says:

> `Faster, stronger, more targeted immune response.`

This can imply every secondary response is simply stronger and better targeted.

Immune memory varies by pathogen, vaccine, cell population, tissue, time, and context. Antibody affinity, cell frequency, localization, response speed, and effector properties can all matter.

### Required revision

Use:

> **Later exposure can produce an altered response because prior exposure changed persistent immune populations or states.**

If brevity is required:

> **Later immune response differs because prior exposure changed the system.**

Do not make `stronger` a universal criterion for memory.

# P1-6 — THE COMPONENT-TURNOVER INSET USES CELLS AS THOUGH THEY REPRESENT ALL TURNOVER CASES

The bottom-left inset says:

> `A system can maintain functionally relevant information even as its components are replaced.`

This is conceptually useful, but the imagery shows cell-like objects dividing/replacing one another.

That makes the inset look specifically biological while the chapter wants Test 5 to be scale-comparative.

Worse, the caption `the stored state persists` implies the same state sits somewhere while components swap around it.

In many systems, persistence may involve copying, redundancy, transfer, reconstruction, distributed maintenance, archives, role replacement, or changing carriers.

### Required revision

Use an abstract carrier-network diagram rather than literal cells.

Show:

**Carrier set A**
→ **partial turnover / transfer / replacement**
→ **Carrier set B**

while a separate information/constraint pathway remains functionally available.

Copy:

> **The carrier can change while functionally relevant information remains available through transfer, replication, distributed persistence, or other system-specific mechanisms.**

Then:

> **PERSISTENCE THROUGH COMPONENT TURNOVER IS A PROPERTY TO EXPLAIN, NOT A VERDICT OF ORGANISMHOOD.**
