The figure has a useful macro-composition: functional stack, biological/technical comparison, tests, AI, and unresolved individuality. But several of the most prominent visual and textual choices encode conclusions stronger than the Chapter 13 architecture permits. Some defects are structural rather than typographic. ---

# PRIMARY HOSTILE QUESTION

If an adversarial reader saw only this figure, detached from the chapter, what would they think the book had claimed?

Likely answer:

> Humanity has built a planet-scale nervous system whose seven brain-like functions are already established; several higher-order tests are already passed; AI is making that global nervous system increasingly brain-like; only consciousness/individuality remains unresolved.

That is **too strong**.

The locked Chapter 13 argument is narrower:

> Humans have constructed overlapping technical and institutional systems that externalize and extend functions such as sensing, transmission, storage, integration, prediction, and control. Functional similarity makes comparison scientifically useful but does not establish nervous-system identity, unified agency, or higher-order individuality.

V2 must visually communicate the second proposition, not merely state it in a disclaimer.

---

# P1-1 — TITLE + SUBTITLE + OPENING PROSE TOGETHER ASSERT THE METAPHOR TOO STRONGLY

The title is intentionally provocative and is locked.

The generated subtitle and opening sentence make the title read literally:

> `From Individual Brains to a Planetary-Scale Information System`

and:

> `We have externalized many functions of the brain into a distributed, technological network. The internet is not a brain, but it functions as a nervous system we built...`

The second sentence directly violates the architecture's primary firewall. The chapter may compare functions; it may not state that the internet **functions as a nervous system** without substantial qualification.

V2 must use the canonical subtitle:

> **From Externalized Human Functions to Planet-Scale Information Infrastructure**

And the opening must be replaced with:

> **Humans increasingly externalize sensing, storage, communication, calculation, prediction, and control into technical and institutional systems. Functional comparison can be useful. Biological identity must be tested, not assumed.**

---

# P1-2 — THE SEVEN-STEP TOP RAIL LOOKS LIKE ONE UNIFIED PLANETARY COGNITIVE LOOP

The sequence:

`SENSING → TRANSMISSION → MEMORY → INTEGRATION → PREDICTION → CONTROL → FEEDBACK`

is visually attractive but currently reads as one coherent system executing one end-to-end nervous-system cycle.

Civilization does not have one demonstrated unified loop of this kind.

V2 must visually label this rail:

> **FUNCTIONS FOUND ACROSS MANY OVERLAPPING TECHNICAL + INSTITUTIONAL SYSTEMS**

Do not use a single uninterrupted arrow that implies one global controller. Use separated modules, branching connectors, or multiple example loops.

`Feedback` should not be a universal seventh stage. Feedback occurs in some specific systems and should be shown as a loop attached to concrete examples.

---

# P1-3 — `INSIDE THE BRAIN` VS `OUTSIDE THE BRAIN` VISUAL CREATES A FALSE TWO-SYSTEM EQUIVALENCE

The brain and glowing Earth-network are shown as two parallel objects joined by a bidirectional arrow and the phrase:

> `DIFFERENT HARDWARE / SAME BASIC FUNCTIONS`

This is the strongest visual overclaim in V1.

It implies that the global network is a second nervous system implemented in different hardware.

Replace the entire comparison in V2.

Use:

**BIOLOGICAL REFERENCE**

versus

**EXTERNAL FUNCTION EXAMPLES**

with a central firewall:

> **SHARED FUNCTION ≠ SHARED MECHANISM ≠ SHARED IDENTITY**

No bidirectional equivalence arrow.

No `same basic functions` label.

---

# P1-4 — THE BRAIN PANEL CONTAINS A CARICATURE OF BIOLOGICAL NERVOUS SYSTEMS

Generated bullets include:

- `~86 billion neurons`
- `Electrochemical signaling`
- `Localized, slow (milliseconds)`
- `Limited memory and processing`
- `Highly efficient, adaptive`

Even where a fragment can be defended in a narrow context, the comparison is scientifically poor. `Slow` depends on comparison and process. `Limited memory and processing` is vacuous. `Highly efficient` needs a metric. The neuron count is unnecessary and can distract into counting equivalences.

V2 should use functional categories only:

- transduction;
- specialized transmission;
- integration/transformation;
- state-dependent modulation;
- learning/storage across timescales;
- output selection;
- feedback;
- coordination within an embodied organism.

Then state:

> **FUNCTIONAL REFERENCE — NOT A ONE-TO-ONE TEMPLATE**

# P1-5 — THE TECHNOLOGICAL PANEL COLLAPSES CIVILIZATION INTO ONE `GLOBAL TECHNOLOGICAL NETWORK`

The figure labels the outside system:

> `Global technological network (many individuals and systems)`

and then attributes `massive persistent memory`, `distributed processing`, and `rapidly expanding capability` to it as though the boundary were settled.

Chapter 12 specifically established that boundaries must be earned.

V2 must instead label:

> **OVERLAPPING TECHNICAL + SOCIAL SYSTEMS — BOUNDARY NOT ASSUMED**

Use several visibly distinct infrastructures/institutions rather than one glowing globe-network object.

V1 shows:

# P1-7 — `CURRENT EVIDENCE` VERDICTS ARE UNSUPPORTED AND MUST BE REMOVED

The bottom rail declares:

- Test 3: `NOT YET`
- Test 5: `PARTIAL`
- Test 8: `YES`
- Test 9: `EMERGING, NOT CONCLUSIVE`

This is not scientifically defensible because no explicit civilization boundary, outcome set, corpus, model comparison, or evidence protocol has been defined.

The most dangerous is:

> **TEST 8 — CURRENT EVIDENCE: YES**

That visually tells the reader the book has already demonstrated whole-only information for civilization.

Remove all evidence verdicts.

Replace with **QUESTIONS TO TEST**.

Test 8 should use the exact architecture logic:

> **Does a relational/system variable improve out-of-sample prediction of a defined outcome beyond appropriate component-only models?**

The tested boundary remains hypothetical.

---

# P1-8 — TEST 9 QUESTION CURRENTLY CONFUSES HIGHER-LEVEL INTERVENTION WITH UNIFIED AGENCY

V1 asks:

> `Does the system act as a coherent whole toward goals across domains?`

That is closer to an agency/individuality question than canonical Test 9.

Replace with:

> **Can a variable defined at the proposed higher level be manipulated in a way that produces reproducible effects on component behavior or system performance beyond an appropriate lower-level description?**

Then add:

> **A USEFUL MACRO-VARIABLE IS NOT YET A NEW INDIVIDUAL.**

# P1-9 — AI PANEL VISUALLY REINTRODUCES THE GLOBAL-BRAIN CLAIM

The glowing AI/brain image inside a server/network environment visually suggests that AI is becoming the brain of the planetary network.

The text `AI systems process, integrate, and act on global information` also collapses many different AI deployments into one system.

V2 should replace the AI brain with neutral technical imagery:

- model/service node;
- database;
- sensor feed;
- software tool;
- human operator;
- actuator/output;

Use several bounded example loops rather than one central intelligence icon.

Canonical firewall:

> **AUTOMATION ≠ AUTONOMY ≠ AGENCY ≠ CONSCIOUSNESS**

And:

> **`THE AI SYSTEM` IS NOT A SCIENTIFICALLY ADEQUATE BOUNDARY UNTIL THE CLAIM SPECIFIES WHAT SYSTEM IS BEING TESTED.**
