# P1-1 — `THE EMERGING GLOBAL INFORMATION SYSTEM` STILL REIFIES A SINGLE SYSTEM

The right-side panel titles the object:

> **THE EMERGING GLOBAL INFORMATION SYSTEM**

and describes billions of people, devices, and institutions as interconnected across the planet.

This is still too ontologically committed. The chapter architecture requires the boundary to remain unresolved.

Replace in V3 with:

> **OVERLAPPING PLANET-SCALE TECHNICAL + INSTITUTIONAL SYSTEMS**

and beneath it:

> **BOUNDARY NOT ASSUMED**

The visual should show several partially overlapping infrastructures, not one glowing global object.

---

# P1-2 — THE TOP HEADER `MANY FUNCTIONS, NOW OUTSIDE OUR BRAINS` IS TOO STRONG

Some functions are extended, externalized, supported, or distributed across tools and institutions; they are not simply `outside our brains` in the sense that the biological role has migrated wholesale.

Replace with:

> **HUMANS HAVE EXTERNALIZED AND EXTENDED MANY TASK-RELEVANT FUNCTIONS**

Then use the canonical architecture distinction:

> **EXTERNALIZED COGNITIVE FUNCTION ≠ EXTERNALIZED CONSCIOUSNESS**

---

# P1-3 — BRAIN VS GLOBAL SYSTEM COMPARISON STILL IMPLIES PARALLEL ENTITIES

The section:

`THE HUMAN BRAIN` ↔ `THE GLOBAL INFORMATION SYSTEM`

with an equivalence-style arrow and `SIMILAR FUNCTIONS / DIFFERENT NATURES` is safer than V1, but the layout still depicts two entity-level objects in direct correspondence.

The chapter should compare **functional categories**, not entities.

V3 should replace the side-by-side entity comparison with:

### BIOLOGICAL FUNCTIONAL REFERENCE

`TRANSDUCE → TRANSMIT → INTEGRATE → MODULATE → STORE / LEARN → SELECT OUTPUT → FEEDBACK`

versus

### EXTERNAL FUNCTION EXAMPLES

sensors, communication networks, archives/databases, models, institutional procedures, bounded control loops.

Between them:

> **SHARED FUNCTION ≠ SHARED MECHANISM ≠ SHARED IDENTITY**

No bidirectional brain↔globe arrow.

# P1-6 — AI PANEL STILL USES A GLOWING BRAIN ICON

The central AI graphic visually implies that AI is becoming the cognitive core of the global system.

That is precisely the kind of metaphor leakage the architecture prohibits.

V3 must use a neutral technical loop, such as:

`SENSOR / DATABASE → MODEL OR SOFTWARE SERVICE → HUMAN / INSTITUTIONAL REVIEW → OUTPUT / ACTUATOR`

with several possible boundaries.

Mandatory:

> **AUTOMATION ≠ AUTONOMY ≠ AGENCY ≠ CONSCIOUSNESS**

# P2-1 — `FUNCTIONS ONCE LIMITED TO INDIVIDUAL BRAINS` IS HISTORICALLY/CONCEPTUALLY TOO ABSOLUTE

Human cognition has always depended on bodies, environments, social partners, language, culture, and artifacts.

Prefer:

> **Functions once more tightly constrained by the capacities of individual humans can now be supported across larger technical and institutional systems.**

---

# P2-2 — SENSING PANEL STILL USES `SOCIAL DATA` AS THOUGH IT WERE A SENSOR MODALITY

Distinguish physical sensors from recorded human behavior or administrative data.

Use subcategories:

- **physical sensing** — satellites, seismometers, weather stations, cameras;
- **human/administrative observation** — surveys, transactions, reports, records.

Do not blur all data collection into sensory transduction.

---

# P2-3 — `NEAR-INSTANT GLOBAL COMMUNICATION` SHOULD BE QUALIFIED

End-to-end latency varies widely.

Prefer:

> **Encoded signals can cross planetary distances far faster than unaided human travel or face-to-face communication.**

---

# P2-4 — `PERSISTENT, REDUNDANT MEMORY AT UNPRECEDENTED SCALE` NEEDS CAUSAL-CARRIER DISCIPLINE

Replace generic memory praise with Chapter 10's causal chain:

`RECORD → PHYSICAL STORAGE → COPYING / MAINTENANCE → COMPONENT TURNOVER → LATER RETRIEVAL → ALTERED ACTION`

Then:

> **GLOBAL MEMORY CAPACITY ≠ A GLOBAL REMEMBERER**

---

# P2-5 — FEEDBACK PANEL UNIVERSALIZES `SYSTEM ADAPTATION`

`A constantly updating system` still suggests one coherent global adaptive entity.

Show feedback only in bounded examples, such as:

- forecast → later score → model update;
- grid demand → control response → measured frequency;
- traffic flow → signal timing → new traffic state.

Then:

> **CLOSED-LOOP CONTROL ≠ UNIFIED AGENCY**

---

# P2-6 — THE OPEN QUESTION PANEL SHOULD USE MODEL COMPETITION RATHER THAN A GIANT QUESTION-MARK EARTH

The content is cautious, but the visual remains rhetorically loaded.

V3 should use the A→D ladder:

A — Individual humans + tools

B — Coordinated institutions

C — Distributed technical-social network

D — Higher-order cognitive individual

Between C and D:

> **ADDITIONAL EVIDENCE REQUIRED**

> **DO NOT PROMOTE C TO D BY ANALOGY.**

This is more scientific and less theatrical.
