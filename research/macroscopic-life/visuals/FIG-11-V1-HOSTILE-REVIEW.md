# P1-1 — THE SIX-BOX FLOW IS PRESENTED AS A UNIVERSAL MECHANISM

The sequence:

`MEMORY → REGULARITY → CURRENT CUE / INTERNAL STATE → ADVANCE PREPARATION → EVENT → PERFORMANCE CONSEQUENCE`

is useful as one analytical route, but V1 visually presents it as though all anticipatory systems literally pass through all six boxes.

That is too strong.

Some anticipatory systems rely on endogenous oscillators shaped by evolution and entrainment, not an individually retained memory trace of prior experience.

Some learned anticipation does involve memory.

Some inherited timing mechanisms exploit recurring structure without requiring memory in the same mechanistic sense.

### Required correction

Add a structural banner:

> **COMPARATIVE ANALYTICAL SCAFFOLD — NOT A UNIVERSAL ANTICIPATION MECHANISM**

And revise box 1 from **MEMORY** to something broader such as:

**PAST STRUCTURE / RETAINED STATE**

with a note:

> May reflect learned history, inherited mechanism, prior entrainment, stored measurements, or other present physical structure.

# P1-2 — `REGULARITY` IS TREATED LIKE A PHYSICAL COMPONENT

The box says:

> `Past events reveal reliable patterns in the environment or within the system.`

A regularity is a relation or pattern an observer or mechanism can exploit; it is not itself automatically a physical carrier.

### Required correction

The figure must distinguish:

- present physical mechanism that has become sensitive to or aligned with it.
