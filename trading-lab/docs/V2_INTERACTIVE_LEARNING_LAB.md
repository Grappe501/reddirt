# V2-06 — Interactive Learning Lab

Status: IMPLEMENTED v1
Date: 2026-09-18

V2-06 changes education from passive reading to demonstrated understanding.

The first exercise bank proves calculation and scenario evaluation across VWAP, P/E Ratio, ATR, Short Selling and Sharpe Ratio. Exercises carry learning objective, difficulty, evaluation contract, explanation and optional simulator configuration.

TRY IT is not a generic quiz page. It is attached to the Knowledge Object and can progressively hand a learner into Trading Lab replay/research context.

Initial exercise set:
- calculate VWAP;
- calculate P/E;
- distinguish ATR volatility from directional prediction;
- calculate simplified short-sale price P/L while explicitly excluding real-world costs;
- recognize what equal historical Sharpe ratios do not establish.

The runtime evaluates deterministic answers locally. Later AI-generated/free-response exercises must use a separate rubric/evidence contract and cannot silently mark subjective financial reasoning correct.

Completion in future phases should feed demonstrated competency, not engagement points. A learner should advance because they can explain, calculate, identify or apply a concept.
