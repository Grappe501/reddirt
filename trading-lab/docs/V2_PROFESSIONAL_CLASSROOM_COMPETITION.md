# V2-19 — Professional / Classroom / Competition Layer

Status: IMPLEMENTED v1 foundation
Date: 2026-09-18

V2-19 makes one Wealth Builder intelligence stack serve four experiences: individual learner, classroom, competition and professional.

Professional mode increases information density but does not remove Universal Explain or the Knowledge Engine; education becomes on-demand.

Classroom mode adds instructor controls for assignments, simulation rules, progress and aggregate competition results. Data exposure remains authorization-dependent.

Competition mode defaults to the original educational idea: $1,000 starting simulated capital over 42 days, with no margin or shorting by default. Rules are versioned and must be equal within a competition.

Two scoring modes are defined. P/L mode is pure normalized return score. Balanced mode weights normalized components: return 40%, drawdown 20%, risk-adjusted performance 15%, rule adherence 10%, research quality 10%, learning 5%. Component scores and weights are visible rather than hidden.

The balanced score is a competition/education mechanism, not a statement that one participant is a better real-world investor. Leaderboards report simulation results only.

No real-money execution is introduced.
