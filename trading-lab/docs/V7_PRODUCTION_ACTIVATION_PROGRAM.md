# V7 Production Activation Program

V6 architecture is complete. V7 is not another conceptual architecture phase. Its job is to turn the proven repository contracts into an operational founding-cohort production system.

## Mission
Burn down the eight V6-16 launch blockers with observable production evidence while preserving every V5/V6 fairness, safety, privacy, simulation-only, sealed-AI, evidence and operator-approval invariant.

## Activation slices
1. **V7-01 Production Deployment Proof** — verify the current main build on the configured Netlify site, canonical shell load, static assets, functions reachability, degraded-state behavior and deploy/build identity.
2. **V7-02 Competition Database Activation** — prove migration 007 through the shared Netlify Database boundary and durable cohort/member/portfolio/fill/credit round trips without alternate database credentials.
3. **V7-03 Competition API Activation** — implement production Netlify functions for allowed competition reads/writes with validation, auditability and simulation-only execution.
4. **V7-04 Verified Human Binding** — bind invitation, email, phone, username, rules acceptance and one-human-one-active-competition-identity controls to production identity/session state. Escalated identity review remains exceptional rather than routine signup.
5. **V7-05 Safe Rendering Closure** — remove unsafe live interpolation paths for user/provider/external strings and prove escaping/text-node rendering across V6 surfaces.
6. **V7-06 Sealed AI Contestant Production Proof** — configure the real provider boundary, freeze contestant configuration/fingerprint, prove the AI uses the same canonical market/execution/accounting path as humans, and prohibit mid-cohort mutation.
7. **V7-07 Rules, Scoring, Start and Privacy Lock** — publish/fingerprint rules, freeze scoring, resolve common market-start logic, close privacy/security review and hostile launch audit.
8. **V7-08 Founding Human Readiness** — operator workflow for ten actual verified humans, integrity review, cohort assignment and 10/10 lock. No fabricated users count as proof.
9. **V7-09 Founding Cohort Launch Rehearsal** — full dress rehearsal using production infrastructure without activating the real cohort; exercise incident rollback and immutable-history protections.
10. **V7-10 Founding Cohort Operator Gate** — assemble evidence packet. Launch remains impossible without explicit operator approval; no automatic launch.

## Definition of done
V7 is complete only when production evidence—not mocks or architecture contracts—satisfies every launch gate. Even then, software readiness and operator authorization remain separate states.
