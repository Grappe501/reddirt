# 11 — Gaps / close / answer the call

## Verbatim (from source)

People say what I’m doing now is impossible. *(pause)* I don’t buy it.  
I didn’t run to put my name on a ballot. *(pause)*  
I ran because there are gaps. *(pause)* And I can fill them. That’s it.  
Once you see the gaps—you can’t unsee them.  
And once you know you can help—you don’t get to sit still.  
We don’t have time to wait.  
So tonight—whatever gap you see… whatever call you feel…  
whatever thing you know is yours to do—don’t wait. Step.  
Because there will be something solid—or you’ll learn how to fly.
