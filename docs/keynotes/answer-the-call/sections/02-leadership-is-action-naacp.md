# 02 — Leadership is action / NAACP

## Verbatim (from source)

Leadership is action.  
I joined the NAACP because of that.  
Because this is an organization that has always been about the work.  
Doing what’s required. Stepping in when it matters.  
Not waiting for perfect conditions.

## Expansion levers

- One sentence: **what “perfect conditions” usually means** (permission, comfort, no risk)—stay generic.
- Bridge: you didn’t join for a title—you joined because **somebody has to carry the clipboard *and* the courage**.

## Word budget

+60–120 words.
