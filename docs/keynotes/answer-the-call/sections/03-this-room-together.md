# 03 — This room / together around the work

## Verbatim (from source)

And I’ve experienced that here.  
People working together. Learning from each other.  
Black, white—different backgrounds, different experiences—  
but coming together around one thing: the work that needs to be done.  
*(pause)* Listening. Learning. Showing up.  
*(pause)*  
Leadership isn’t about who gets the credit.  
It’s about whether the work gets done.

## Expansion levers

- Repeat **listening / learning / showing up** as a *triad* with a breath between each (delivery, not new facts).
- Optional: “Credit is cheap. Completion is rare.” (only if you like the line—cuts or stays).
