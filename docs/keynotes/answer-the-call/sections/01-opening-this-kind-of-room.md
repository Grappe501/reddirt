# 01 — Opening: “This is my kind of room”

## Verbatim (from source)

Good evening.  
*(pause)*  
This is my kind of room.  
*(pause)*  
Because this is a room that understands the work.  
Not just talking about it—doing it. Showing up. Getting it done.  
*(pause)*  
That’s how I was raised.  
That’s how I try to live.

## Expansion levers (no new facts)

- Name **one sensory detail** you actually remember about rooms like this (lights, warmth, noise)—*only if true*; if none, skip.
- Linger on the contrast **talk / do** with a second beat: “I’ve been in rooms where everybody leaves inspired and nothing moves. This isn’t that.”
- Short land: **tonight** is about the **habit** of work, not the hype of work.

## Word budget

+80–150 words for ~30–60 seconds.
