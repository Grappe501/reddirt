# Electd public forms packet

Send the whole `docs/partners/electd/` folder (or the zip) to Electd.

Files:

1. `SEND_THIS_TO_ELECTD.txt` — paste into the email
2. `ELECTD_PUBLIC_FORMS_PACKET.md` — human-readable spec (read first)
3. `ELECTD_FIELDS.csv` — one row per field
4. `ARKANSAS_COUNTIES.csv` — 75-county dropdown, exact spellings
5. `ELECTD_FORMS.json` — short machine-readable index

Do not publish this folder on the public website. It is a partner handoff, not voter copy.
