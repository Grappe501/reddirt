## Public-site “Across Arkansas” experience (doctrine)

Use existing surfaces — do not add a new product:

| Surface | Role |
| --- | --- |
| Homepage `#across-arkansas` | Video + confirmed stills + quiet confirmed-community line |
| `/about/journey` | Full journey proof |
| `/campaign-photos` | Gallery of curated FEATURE set |
| County links | Only when county confirmed (`*-county` slugs) |

Every confirmed county strengthens the impression. Abstraction (adjectives about “statewide”) loses to evidence (named places).
