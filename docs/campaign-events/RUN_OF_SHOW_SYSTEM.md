# Run of show system

**Sprint 6** — stored in `_eventPlanning.runOfShow`.

## Row model

| Field | Purpose |
|-------|---------|
| time | Clock time or relative label |
| action | What happens |
| owner | Responsible person |
| location | Where |
| materials | What to bring |
| notes | Free text |
| status | planned / confirmed / done / skipped |

## Tools

- `run-of-show-generator` — draft from fact card times and host/CM defaults
- `run-of-show-gap-detector` — missing time/action/owner
