# NSI Elite Intelligence Roadmap

**Question:** If Steve funded **10 more major passes** after NSI-15, what would make this the most advanced campaign intelligence operating system in America — not CRM, not a chatbot, but a **Campaign Intelligence Agency** embedded in software?

**Audit date:** 2026-05-29  
**Current baseline:** NSI-1–15 LIVE · Governance ~93% · Command center ~32% · Elite ambition ~42%

---

## What you already have that most campaigns never build

1. **Governed opposition research OS** with claim/citation/export safety (rare at any level)  
2. **36 deterministic copilots** with explicit prohibited actions  
3. **LLM gate** that cannot publish  
4. **Cross-slice intelligence graph** linking bills, counties, narratives, citations  
5. **Scenario + memory + action queue** closing the loop from “what if” to “what should a human do”  
6. **Debate prep stack** tied to evidence, not vibes  

That is already above 95% of state campaigns. Elite tier requires **pace, unity, prediction discipline, and institutional rhythm**.

## Missing capabilities (honest list)

### Critical (blocks “elite” label)

1. **Unified command center** (NSI-16)  
2. **Hosted persistence for intelligence artifacts**  
3. **Production media/opponent monitoring cadence**  
4. **Calibrated forecasting discipline** (assumption-labeled, not hype)  

### Important (differentiation)

5. Weekly intelligence packet factory (PDF/MD, governed)  
6. Debate Night Command mode  
7. Red team / quality attack on own messages  
8. Collection requirements matrix (what we still need to know)  
9. Source ADMIT/confidence formalization  
10. Intel production calendar (who produces what when)  

### Advanced (America-tier ambition)

11. Multi-language border media (OK/TX/MO/TN signals)  
12. Surrogate & validator packet automation (human export)  
13. Coalition / endorsement intelligence (governed, no invented names)  
14. Precinct **aggregate** battle map (turnout bands, not individuals)  
15. Post-election institutional archive mode

## Steve’s strategic choice

**Path 1 — Operator-first (recommended):** NSI-16 → 17 → 18. Win the daily workflow before more AI glitter.

**Path 2 — Collection-first:** NSI-20 → 18 → 16. Feed the machine before unifying the UI.

**Path 3 — Forecast-first:** NSI-19 → 16. Risky — pretty charts without habit formation underuse the stack.

**Burt recommends Path 1.** The OS is already analytically deep; it is not yet **operationally habitual**.
