# Compliance source truth audit

Generated by `npm run compliance:source-truth-audit`. Machine output: `data/compliance/ai/source-truth-audit.json`.

## Purpose

Scan all compliance JSON authority stores and report whether each source category is present, usable, and able to satisfy the bank reconciliation requirement **without** assuming `bank-april-2026.csv` is the only path.

| Category | Location | Satisfies bank CSV? |

## Operator rules

1. **File missing ≠ data missing** — check import chunks before telling operators the bank is absent.
2. **Do not invent bank rows** — only file CSV or admin bank import staging creates bank credits.
3. **GoodChange is not bank** — never mark bank green from payout export alone.
4. **Privacy** — audit JSON uses counts and paths only; no donor PII in committed output.
