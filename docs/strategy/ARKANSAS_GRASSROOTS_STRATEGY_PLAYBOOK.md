# Arkansas Grassroots Strategy Playbook

This playbook captures baseline Arkansas grassroots campaign operating patterns for read-only strategy doctrine intake (Phase 5A).

## Core Arkansas campaign culture assumptions

- Counties differ materially in culture, power structure, and message credibility filters.
- Local messengers and known relationships matter.
- Courthouse, coffee shop, fair/festival, civic-club visibility carries trust value.
- Local radio and newspaper moments remain meaningful.

## Baseline organizing patterns

- County captain ladder with city/precinct captain handoffs.
- Neighbor-to-neighbor relational pushes.
- Phone tree readiness cycles.
- Event visibility tied to follow-up loops.

- This is a doctrine-intake scaffold, not final strategic guidance.
