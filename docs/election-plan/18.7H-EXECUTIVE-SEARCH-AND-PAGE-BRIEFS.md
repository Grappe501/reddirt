# 18.7H — Election Plan Executive Search & Page Summary Layer

Password-protected search and page summaries for the Election Plan portal. **Local corpus only** — no external web search, no admin data, no voter/donor/private contact files.

## What ships

| Layer | Component / route | Purpose |
| ----- | ----------------- | ------- |
| **Page summaries** | `PageBrief` · `PageBriefFromPath` | “What’s on this page” block on every drill-down |
| **Global search bar** | `ElectionPlanPortalHeader` | Sticky search on all `/election-plan/*` pages |
| **Search UI** | `/election-plan/search?q=` | Result cards with type, excerpt, confidence, source path |
| **Search API** | `GET /api/election-plan/search?q=` | Keyword search + optional OpenAI summary from local hits only |
| **Index builder** | `scripts/election-plan/build-election-plan-search-index.ts` | Rebuild allowlisted corpus |

## Page brief registry

**File:** `data/campaign-brain/election-plan/page-briefs.source.json`

**Fields:** `title` · `answers` · `keyMetrics` · `bestFor` · `relatedLinks`

**Routing:**

- `pathPattern` + `exact` — URL match
- `tabPattern` — matches `/election-plan?tab=weeklyDashboard` etc.
- Dynamic enrichment — county/city/campus slugs get human titles from URL

**Auto-applied on:** portal layout (`src/app/election-plan/(portal)/layout.tsx`) except hub home, search page, and Executive Book chapters (those use inline briefs).

## Search result card

Each hit shows:

- **Title**
- **Type** — Executive Book · Doctrine · County · City · Campus · Calendar · Budget · Message · Academy · Public Website · …
- **Excerpt**
- **Link**
- **Confidence** — high / medium / low (keyword score)
- **Source path** — local file for audit

## Keyword vs Brain (AI)

1. **Keyword search always works** — no OpenAI required.
2. **Optional AI layer** — when `OPENAI_API_KEY` is set and `?ai=1`, summarizes top local hits only.
3. **AI rules** — must cite `href` + `sourcePath`; never invent; say “Needs human verification” when uncertain.

This is **RedDirt Brain–compatible local retrieval**: same firewall as campaign brain docs; future semantic chunks can merge with `election-plan:` path prefix under identical exclusion rules.

## Auth

- Portal: `ELECTION_PLAN_PASSWORD` session cookie via middleware + layout.
- API: `/api/election-plan/search` verifies the same cookie in the route handler (middleware skips `/api/*`).
