## Program scorecards (monthly)

### Registration (**LANE §2**)

- YTD new regs vs **50K** ambition progress curve.  
- **Tier 1** counties **below 80%** pro-rata **4 weeks** → **red** flag.  
- Partner trainings / month.

### Turnout gap

- Cohort **first / second touch** rates (defined in data SOP).  
- **T-21** readiness: % gap universe with **vote plan**.

### Persuasion

- ID/support + **cost per ID** by county tier.  
- **Freeze** new tests after **T-7** — binary compliance check.

### Youth

- School events; **18–24** indicators; **dorm** address updates count.

### Relational

- Active hosts; gatherings; **captains named** vs **Tier 1** list.

### Budget

- Actual % vs **LANE §4.2** — **travel**, **media**, **mail**, **people**, **contingency**.  
- **Lockbox** balance vs **§4.3** minimum.

### GOTV (E-season: **weekly → daily**)

- **§6.4** scoreboard — shifts, rides, hotline SLA, Tier 1 visibility checklist.

## RedDirt alignment (reporting honesty)

- **Strong:** email telemetry (when live), county metrics, tasks/events, ledger.  
- **Partial:** GOTV assignment automation, SMS live.  
- **Manual:** LTE, some volunteer hours — **until** native.

**Rule:** If RedDirt **cannot** report a **LANE** metric, **one** spreadsheet owner is named in standup.
