## 3. Tactics (expanded)

### 3.1 Polling / EV visibility

- **Buffer** distances per jurisdiction — **laminated** card per volunteer.  
- **Tier 1:** aim **legal** visibility at **all** EV sites **≥ 1** shift; **E-Day** **priority** sites first.  
- **Tier 3:** **best effort** — kits pre-positioned **T-14** if volunteer exists.

### 3.2 Kits (**per volunteer**)

- Tees/hat; **hours** palm; push card; water; **sun/rain**; **chair** if older volunteer; ** charged** phone; **lawyer** card.

### 3.3 Incidents

- **Photo/video** only if safe; **de-escalate**; **call** legal — **never** physically engage.

### 3.4 After vote

- **Thank-you** SMS/email **48h** — pivot to **gratitude** + **donor** retention (**Part 13**).
