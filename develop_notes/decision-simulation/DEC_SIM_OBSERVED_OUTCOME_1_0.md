# DEC-SIM-OBSERVED-OUTCOME-1.0

**Status:** Phase 10 outcome-learning capability. Not a Phase 10 close.  
**Accessed:** 2026-09-09

An operator can attach a real public reply, map it to a named future, tag the observed frame, and see a compare: frame hit/miss, lexical overlap with the predicted first response, and a lexical future guess.

A model-change proposal is stored as `PENDING_OPERATOR_APPROVAL` with `applied: false`. Writeback is `FORBIDDEN`. Prompts and personality versions do not change.

Not in this slice: database write to `decision_simulation_outcome`, embeddings, accuracy-over-time charts, automatic personality versioning. Filed as **V2-35**.
