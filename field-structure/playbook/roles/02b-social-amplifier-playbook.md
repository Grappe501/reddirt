# Social · amplifier playbook (step-by-step)

## Monday (20–30 minutes)

- [ ] Read the week’s HQ theme in one pass.
- [ ] Write **3 local hooks** (place names, local allies, local headlines — carefully).
- [ ] Schedule **minimum viable cadence** for the week.

## Wednesday (20–30 minutes)

- [ ] **Proof-of-work post** — a volunteer photo/story (consent on file).
- [ ] Identify **two locals** to uplift via comment/repost/share (platform-appropriate).

## Friday (15–20 minutes)

- [ ] **Recruitment CTA** — one sentence, one link/DM path.
- [ ] Log highlights for county/state: what caught fire?

## Daily micro-discipline (5 minutes)

- [ ] Respond to **volunteer questions** within 24h or escalate.
- [ ] Track misinformation replies → **escalate**, don’t freestyle legal/process claims.

## If a post goes wrong

- [ ] Screenshot for internal review.
- [ ] **Pause** additional replies if emotions spike.
- [ ] Notify HQ/campaign coordinator per protocol.
