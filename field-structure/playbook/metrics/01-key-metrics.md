# Key metrics & reporting

Metrics exist to **help volunteers win**, not to create spreadsheet theatre. Keep definitions stable for 30 days before changing.

## Core set (from the originating playbook)

1. **Teams launched** — new triads meeting weekly standard.
2. **Volunteers recruited** — names with lane assignment or training path.
3. **Contacts made** — intentional conversations or verified outreach touches (define locally).
4. **Events held** — executed public or partner-hosted touches with documented outcomes.
5. **Social reach** — use conservative platform metrics; prioritize **inbound volunteer asks**.

## Definition discipline

For each metric, write down:

- **What counts** (example vs non-example)
- **Who logs**
- **Where it lives**
- **How often it refreshes**

## Weekly report (5 bullets)

Recommended structure:

1. Total **teams** active + new.
2. **Volunteers** new + in training pipelines.
3. **Contacts** vs plan.
4. **Events** executed + next 14-day lookahead.
5. **Social** highlights + questions needing HQ.

## Avoid

- Vanity totals that confuse activity with results.
- Hidden shadow spreadsheets — one source of truth.

## Redaction & safety

Public dashboards should **not** expose volunteer PII or sensitive relational maps. Share summaries, not raw lists, outside trusted ops.
