# Three-person exponential organizing model

This playbook turns a simple **three-person team** into a **fractal field plan**: the same roles repeat at state, county, city, precinct, and neighborhood layers so volunteers always know what “good” looks like.

## Core concept

Every organizing unit has **three coordinators**:

1. **Events** — local gatherings that create momentum and onboarding moments.
2. **Social** — digital amplification, content discipline, and online recruitment.
3. **Power of 5 / relational** — intentional 1:1 and small-circle outreach that compounds trust.

Each team recruits and launches **additional three-person teams** at more local levels. Growth is exponential because **structure stays simple** while **geography gets specific**.

## What volunteers are actually signing up for

- About **one hour per week** executing a short, defined task list.
- **One person** from the team should represent the unit at the **weekly huddle** (not necessarily the same person every week).

## How to use this site

1. Read **Fractal model** to see how layers nest.
2. Open your **layer** (state, county, city, precinct, neighborhood).
3. Open your **role** and the matching **step-by-step playbook**.
4. Run the **weekly huddle** agenda with your triad.
5. Read **[Self-Building Team System](/field-playbook/overview/self-building-team-system)** for how teams self-govern toward GOTV.
